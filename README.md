# Todo CLI

Sistema de gerenciamento de tarefas no terminal.

## Como usar
```bash
node todo-cli.js
```

## Funcionalidades
- Adicionar tarefas com prioridade
- Marcar como concluída / remover
- Buscar por texto
- Estatísticas da lista

## O que aprendi
- Lógica de programação com JavaScript
- Array methods: map, filter, find, reduce
- Funções puras e imutabilidade

## Tecnologias
Node.js · JavaScript ES6+
